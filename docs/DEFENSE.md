# Что показать на защите практик №9–11

Чернышев Антон Дмитриевич, ЭФБО-02-25.

Можно начать так: «Тема моего отдельного проекта — пешие маршруты и экотропы России. Тема согласована с преподавателем. Я применил сетку и компоненты Bootstrap из практик 9–11 к каталогу маршрутов. На сайте четыре страницы, контакты находятся в общем подвале».

## Практика №9

Открыть главную `index.html`. Показать шапку, меню, hero с текстом и фотографией, преимущества, три карточки и подвал. Сузить окно: колонки перестраиваются.

В коде показать `container → row g-4 → col-12 col-lg-6` у hero: на телефоне колонка занимает всю строку, от 992 px — половину. У карточек `col-12 col-md-6 col-lg-4`: одна, две, три карточки в строке. Сетка делится на 12 частей; 6/12 — половина, 4/12 — треть. `g-4` задаёт промежутки, число 4 — уровень шкалы Bootstrap, не четыре пикселя.

В `head` показать подключение Bootstrap CSS, затем `custom.css`, а также JS Bundle с `defer`. Библиотека подключена локально: папка `vendor/bootstrap`. В базовом примере тетради используется CDN, локальный вариант описан среди доработок в тетради №11. Наш `custom.css` только уточняет шрифт, цвет hero, размеры фотографий и несколько деталей.

## Практика №10

| Что показать на сайте | Где найти в коде |
| --- | --- |
| Меню и мобильная кнопка | Каждая страница: `navbar navbar-expand-lg`, `data-bs-toggle="collapse"`, `#site-menu` |
| Шапка остаётся сверху при прокрутке | `header.sticky-top`; это sticky, а не fixed |
| Карточки маршрутов | `catalog.html`: `article.card`, `card-body`, `card-title`, `card-text` |
| Разные кнопки | `btn-success`, `btn-outline-success`, `btn-outline-secondary` |
| Метка сложности | `badge` на карточке и странице маршрута |
| Поиск и фильтры | `catalog.html`: `#filters`; `js/main.js`: `updateCatalog()` |
| Описание нужного маршрута | Ссылка `route.html?id=baduk`; поиск ID в `js/routes.js` |
| Таблица характеристик | `route.html`: `table`, `caption`, `th scope="row"` |
| Частые вопросы | `index.html`: `accordion`, `data-bs-toggle="collapse"` |
| Модальное окно | `#feedbackModal`, кнопки `data-bs-toggle="modal"` и `data-bs-target` |
| Форма | `#feedback-form`: `form-control`, `form-select`, `input-group` для +7 и `form-check` |
| Сообщения | `alert-info` перед формой и `alert-success` после проверки |

Поиск: набрать «Бадук», выбрать несовместимую сложность — появится пустой результат. Нажать «Сбросить» — снова шесть маршрутов. Объяснить: `data-*` хранит параметры карточки, обработчик сравнивает их с полями и меняет свойство `hidden`.

Страница маршрута: параметр URL `id` используется только для выбора существующего объекта из массива. Неизвестный ID показывает ошибку. Тексты вставляются через `textContent`, а не через HTML из адреса.

Открыть форму со страницы маршрута: нужный маршрут уже выбран. Кнопка передаёт ID через `data-route`, обработчик `show.bs.modal` подставляет его в select. Проверить пустые поля, неправильный email, телефон не из 10 цифр и отсутствие согласия. `label for` связывает подпись с `id`; `name` задаёт имя поля, `required` делает его обязательным, `pattern` проверяет телефон.

Заполнить вымышленными корректными данными. Результат означает только учебную проверку. В `js/main.js` показать `preventDefault()`: запрос к серверу не выполняется, backend нет. Разработчик не может просмотреть такие «отправленные» обращения. Без JS отправка отключена.

## Практика №11

Продемонстрировать итоговые четыре страницы на компьютере и в мобильном режиме DevTools, обязательные компоненты, README со структурой и источниками, историю коммитов и Pull Request из `feature/bootstrap-components` в `main`. Названия `route.html` и `preparation.html` соответствуют согласованной предметной области; форма находится в модальном окне, отдельной страницы заказа нет.

В СДО студент сдаёт ссылку на репозиторий по указаниям преподавателя. Устную сдачу и загрузку за студента не выполняли. Вторая часть тетради №11 — постановка будущей КР №3: по исходной методичке она строится на HTML/CSS-магазине КР №1 и выполняется отдельно. В этот сайт она не включена.

## Важные ограничения

- Каталог не показывает, открыт ли маршрут сегодня. Перед посещением нужно перейти к официальному описанию парка.
- Фильтр длины использует число, написанное в карточке. Если это путь в одну сторону, возвращение нужно учитывать отдельно.
- Сложность — условная учебная оценка, не спортивная категория.
- Фотографии — иллюстрации пейзажей с Unsplash, не снимки этих маршрутов.
- Список вещей — обычные чекбоксы, отметки не сохраняются после перезагрузки.
- Прежние магазины КР №1 и №2 находятся в других папках и репозиториях.
