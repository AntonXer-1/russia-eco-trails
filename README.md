# Пешие маршруты и экотропы России

Учебный проект по практическим работам №9–11. Тема согласована с преподавателем.

Автор: Чернышев Антон Дмитриевич, ЭФБО-02-25.

Четыре страницы доступны из меню Bootstrap: главная, каталог, подготовка и «О проекте». Каталог открывает отдельный шаблон описания маршрута. Контакты и общая навигация находятся в подвале каждой страницы. Поиск и фильтры работают в браузере; форма обратной связи демонстрационная.

## Как работа связана с тетрадями

В тетрадях №9–11 пример называется `kr2-bootstrap-shop` и описывает магазин. По согласованному с преподавателем заданию здесь выполнен отдельный сайт другой предметной области: маршруты и экотропы. Прежние проекты КР №1 и КР №2 остаются отдельными репозиториями.

| Практика | Реализация |
| --- | --- |
| №9 — Bootstrap-сетка | Отдельный репозиторий; главная с шапкой, navbar, двухколоночным hero, преимуществами, карточками и подвалом. Используются container, row, col-12/col-md-*/col-lg-*, g-*, utility-классы. |
| №10 — компоненты | Navbar/collapse, card, btn, badge, alert, modal; форма с form-control, form-select, input-group и form-check; дополнительный accordion для FAQ. Работа в feature/bootstrap-components с Pull Request в main. |
| №11 — итоговая проверка | Проверены страницы, компоненты, адаптивность и ссылки; подготовлены README и отдельный репозиторий для демонстрации результата. Сдачу в СДО и устную защиту выполняет студент. |

Имена страниц адаптированы под согласованную тему: вместо `product.html` — `route.html`; отдельная форма `order.html` заменена модальным окном в описании маршрута. Четвёртая страница — `preparation.html`, как согласовано с пользователем. Контакты находятся в подвале. Страница «О проекте» добавлена по замечанию преподавателя.

Практики №9–11 на сайте маршрутов приняты преподавателем как допуск к КР №3. По отдельно согласованному заданию КР №3 продолжает этот сайт.

## КР №3

- **Тема.** Кнопка в шапке переключает `data-bs-theme` у элемента `html`. CSS плавно меняет фон и текст, а при системной настройке уменьшения движения переход отключён. Выбор сохраняется в `localStorage`.
- **Кабинет.** На `account.html` можно зарегистрироваться, войти и выйти. `js/profile.js` хранит профили в `localStorage`, а текущий вход — в `sessionStorage` вкладки. Для проверки пароля используется PBKDF2 с индивидуальной солью. Это локальная демонстрация входа, данные можно изменить через инструменты браузера.
- **Избранное.** Кнопки в каталоге и на странице маршрута сохраняют его ID для текущего профиля. Страница `favorites.html` выводит сохранённые маршруты и позволяет их убрать.
- **Мастер маршрута.** В кабинете пользователь вводит название, регион, длину и описание, проверяет предпросмотр и сохраняет маршрут. Результат виден в «Моих маршрутах» этого профиля. Данные доступны в том же браузере и исчезают при очистке хранилища сайта.
- **Помощник по маршрутам.** Кнопка справа внизу открывает окно с быстрыми вопросами и полем ввода. `js/help.js` подбирает ответы из массива по ключевым словам, а длину, время и координаты берёт из `js/routes.js`. Помощник помнит упомянутый маршрут до ухода со страницы. Вопросы обрабатываются в браузере. Для связи с автором есть отдельная ссылка на почту.

## Технологии и Bootstrap

HTML, CSS, небольшой JavaScript, Bootstrap 5.3.8, Git и GitHub. Сборщик, React/Vue, backend и базы данных не используются.

Bootstrap подключён **локально**, что в тетради №11 описано как самостоятельная доработка. В базовом примере №9 используется CDN; здесь файлы библиотеки размещены в проекте. Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`.

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css?v=20261113">
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js" defer></script>
```

Собственные стили подключены после Bootstrap. JS Bundle обеспечивает работу меню, модального окна и FAQ. Ресурсы сайта, включая фотографии, загружаются из самого проекта; Bootstrap не зависит от CDN. Внешний виджет Яндекс Карт загружается автоматически на странице маршрута.

## Что работает

- Хлебные крошки на внутренних страницах. В описании маршрута показано его название и есть переход обратно в каталог.

- Поиск по названию и региону без учёта регистра, крайних пробелов и различия е/ё.
- Совместные фильтры по условной сложности и указанной длине (до 2 км включительно / больше 2 км).
- Счётчик результатов, сообщение при пустом поиске и кнопка сброса.
- Переход на описание именно выбранного маршрута. Неизвестный `id` даёт сообщение с возвратом в каталог. Без `id` показываются Бадукские озёра.
- Яндекс Карта с меткой начала каждого маршрута открыта сразу. Координаты указаны над картой.
- Закреплённая шапка `sticky-top`, раскрывающееся мобильное меню, кнопка «Наверх» и FAQ из восьми вопросов.
- Учебная форма в Bootstrap modal с выбранным маршрутом, именем, email, телефоном, комментарием и обязательным согласием. Телефон — 10 цифр без префикса +7; email проверяется браузером. Подписи связаны с полями через for/id.
- Список вещей на странице подготовки — обычные чекбоксы; состояние действует до перезагрузки.

Форма использует `preventDefault()`, не делает POST/fetch и ничего не сохраняет. Сообщение об успехе означает только успешную учебную проверку полей. Без JavaScript кнопка формы и фильтры отключены; статические карточки и страница подготовки доступны. Для выбранного описания маршрута нужен JS, об этом есть сообщение `noscript`.

## Описание данных

В каталоге две территории: Тебердинский национальный парк и «Красноярские Столбы». Длины и время сверены с официальными источниками; при необходимости явно указано «в одну сторону». Фильтр сравнивает именно приведённое число, а не гарантированную полную длину прогулки с подходом и возвращением.

Сложность — условная редакционная оценка для демонстрации фильтра, не официальная категория. Текущий статус открытия, погода, цены и бронирование не моделируются. Названия парков указаны на страницах, ссылки на официальные описания собраны в [списке источников](docs/SOURCES.md). Пейзажи на главной — иллюстрации. В карточках используются фотографии мест и геопривязанные наблюдения природы из окрестностей троп. Авторы и лицензии указаны в списке источников.

## Запуск

Из папки проекта:

```sh
python3 -m http.server 8000
```

Открыть http://localhost:8000/ . Можно также использовать Live Server. Для статических страниц сборка не требуется.

## Проверка

Нужны Node.js, Playwright и установленный Chromium:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium --only-shell
node --test tests/site.test.cjs
```

При использовании внешнего Playwright указать его каталог в `NODE_PATH`; при отдельном расположении браузера — `PLAYWRIGHT_BROWSERS_PATH`. Переменная `SITE_URL` позволяет запускать те же проверки для опубликованного сайта (с завершающим `/`).

Браузерные проверки охватывают семь HTML-страниц, ссылки, карты, адаптивность, каталог, модальную форму, мобильное меню и FAQ. Сценарий КР №3 проверяет сохранение темы, регистрацию, вход и выход, избранное и сохранение личного маршрута.

Вручную проверены изображения компьютерной и мобильной версий.
